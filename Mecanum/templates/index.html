Join a Wi-Fi network

Choose a nearby network or enter its exact name. A successful connection becomes the preferred network used at the next boot.

The web setup supports PEAP with MSCHAPv2 and validates the server using the Pi's system certificates. Use nmtui over SSH for other enterprise configurations.

Start the robot hotspot

This disconnects the Pi from its current Wi-Fi for this boot. On the next boot it tries the preferred Wi-Fi for 30 seconds before falling back to the hotspot.

After switching, join the robot hotspot on this computer and open http://10.42.0.1:8080. The default password on a fresh install is motionrobot.
