# Mecanum Mini sample

The same four-wheel robot, autonomous, sensor and dashboard code as
[Mecanum](../Mecanum), using a Mini hardware definition: two dual H-bridge
boards and four motor channels. All sixteen PCA9685 servo channels and the
Pi-connected MPU6500 remain available.

Use the [Mini setup](../../MotionModuleMini/README.md),
[Mini parts list](../../MotionModuleMini/BOM.md) and
[Mini pinout](../../MotionModuleMini/PINOUT.md). No spare motor channels are
configured; channels 1–4 keep their locked pins and wheel names.
